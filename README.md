# Bangla Document Converter

Developer: Chowdhury Emon

Bangla Document Converter converts legacy Bijoy/SutonnyMJ Bangla DOCX files to Unicode Bangla and applies Nikosh to Bangla text. English/Latin text is normalized to Times New Roman, while preserving document structure, tables, formatting, and the original source DOCX.

## Features

- Converts Bijoy/SutonnyMJ Bangla to Unicode Bangla
- Applies Nikosh to Bangla text
- Converts English/Latin text to Times New Roman
- Preserves document structure and formatting
- Preserves tables and nested content
- Keeps the original source DOCX unmodified
- Works as a standalone Windows application
- Does not require Python for end users
- Bundles the Node.js runtime locally
